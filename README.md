# Trickshot Abyss · 弹无虚坑

English | [简体中文](README.zh-CN.md)

A ball-bouncing roguelite that runs in the browser. Shoot balls into the enemy formation marching down at you, then bounce, catch, level up and fuse your balls into stronger evolutions as you fight your way down the pit, layer by layer. The gameplay is a tribute to _BALL x PIT_.

> **Unofficial fan project.** Not affiliated with or endorsed by Kenny Sun or Devolver Digital. All graphics and sounds are generated by code, and no assets from the original game are used. See [ATTRIBUTION.md](ATTRIBUTION.md).

> **The in-game text is currently Chinese only.** English localization is planned.

## How to play

| Action | Input |
|---|---|
| Move | WASD / arrow keys |
| Aim | Mouse (upwards only, at least 20° above horizontal) |
| Shoot | Hold left mouse button / Space (auto-fire is on by default) |
| Toggle auto-fire | F / middle mouse button |
| Recall stuck balls | Right mouse button / R (once a ball has been out for 6 s) |
| Game speed | 1 / 2 / 3, or the `>` `>>` `>>>` buttons in the top right |
| Pause / mute | Esc / M |

On phones and tablets in landscape, drag on the left side to move and hold on the right side to aim and shoot.

- Balls bounce off the walls, the back of the pit and enemies. A ball that leaves through the bottom takes a moment to come back, but **catching it with your body** re-fires it immediately.
- Enemies advance with the scrolling floor. Get too close and they hit you in melee; any that reach the bottom also deal damage.
- Kills drop XP gems that you have to walk over. Each level-up offers three choices: a new ball, a ball upgrade, a new passive or a passive upgrade. You have 4 ball slots and 4 passive slots, and everything maxes out at level 3.
- Mini-bosses always drop a rainbow **Fusion Reactor**, which offers Fission, Fusion or Evolution. Evolving requires every ingredient ball at level 3, for example Burn + Iron = Bomb.
- Each layer has three segments. The first two end with a mini-boss, after which the pit widens. The last ends with the layer's boss.
- Clearing a layer unlocks the next one plus new characters, balls and passives. Progress is saved in each player's browser.
- At the end of a run you can enter your name on the shared leaderboard, which is shown on the title screen.

## What's in it

- **Two layers:**
  - The BONExYARD: mini-bosses Skeletal Brigade and Bone Ballista, boss Skeleton King.
  - The SNOWYxSHORES: mini-bosses Icebound Champion and Icebound Howler, boss Icebound Queen.
- **Balls:** 16 base balls and 45 evolutions. Any two maxed balls can be fused.
- **Passives:** 38 base passives and 8 evolved ones, including passives that summon allies such as stone soldiers and a golden bull.
- **Characters:** 7, each with its own quirk.
- **Shared leaderboard** served by the bundled server.

Not done yet: the other 6 layers, town building and meta-progression, and more characters.

## Play online

The single-player game is published to GitHub Pages: <https://0xgwf.github.io/trickshot-abyss/>. It is the same build without a server, so it has no leaderboard. Progress is saved in your browser.

## Run and deploy

Requires Node.js 22.18 or newer.

```bash
npm install
npm run build    # type-check and build into dist/
npm run serve    # serve the game and leaderboard on 0.0.0.0:8080 (set PORT to change it)
```

To keep it running in the background:

```bash
setsid nohup node server.mjs > server.log 2>&1 < /dev/null &
kill $(pgrep -f '^node server.mjs$')   # stop
```

Leaderboard entries are stored in `data/scores.json`; delete the file to reset the board. Set `DATA_DIR` to store it elsewhere.

## Development

```bash
npm run dev                 # Vite dev server (no leaderboard in this mode)
npm run check               # Prettier format check + TypeScript type check
npm run format              # fix formatting
npm run sim -- 20           # play 20 headless runs with the autopilot: win rate, run time, damage taken
node tools/shot.ts <dir>    # play a run in headless Chrome and save screenshots (needs /usr/bin/google-chrome)
```

- Stack: TypeScript, Vite, Canvas 2D and Web Audio, with no runtime dependencies. The server only uses Node's built-in `http` module.
- `src/game/` is pure game logic with no browser APIs, which is why it can run headless in Node (`tools/sim.ts`).
- Numbers live in `src/game/config.ts` and `src/game/data/*.ts`. `docs/NOTES.md` explains which values come from the original and which are estimates; sources are listed in `ATTRIBUTION.md`.
- Commit conventions and checks are described in [CONTRIBUTING.md](CONTRIBUTING.md) (in Chinese for now).
