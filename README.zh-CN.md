# 弹无虚坑 · Trickshot Abyss

[English](README.md) | 简体中文

一个在浏览器里玩的弹珠肉鸽：发射弹珠打碎往下压来的敌阵，靠反弹、接球、升级和融合进化，一层层打到坑底。玩法致敬《BALL x PIT》（球比伦战记）。

> 非官方粉丝作品，与 Kenny Sun、Devolver Digital 无关。画面和音效全部由程序生成，没有使用原作的任何素材。详见 [ATTRIBUTION.md](ATTRIBUTION.md)。

## 怎么玩

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标（只能朝上方发射，最低 20°） |
| 发射 | 按住左键 / 空格（默认开着自动射击） |
| 自动射击开关 | F / 鼠标中键 |
| 召回卡住的球 | 右键 / R（弹珠飞出 6 秒后可用） |
| 游戏速度 | 1 / 2 / 3，或点右上角的 `>` `>>` `>>>` |
| 暂停 / 静音 | Esc / M |

手机或平板横屏也能玩：在左侧拖动是移动，在右侧按住是瞄准并射击。

- 弹珠会在墙壁、坑道顶端和敌人之间反弹。从底边飞出去的球要过一会儿才会回到手里，**用身体接住**可以立刻再发射。
- 敌人会跟着地面往下推进。靠得太近会挨近战，冲到底部的敌人也会打你一下。
- 击杀会掉经验宝石，得走过去捡。升级时三选一：新弹珠、升级弹珠、新被动、升级被动。弹珠和被动各有 4 个栏位，最高 3 级。
- 精英首领必掉彩虹色的「融合炉」，可以选择裂变、融合或进化。进化需要配方里的弹珠全部升到 3 级，比如燃烧 + 黑铁 = 炸弹。
- 每层分三段：前两段末尾各有一个精英首领，击败后坑道拓宽；最后是关底首领。
- 通关会解锁下一层、新角色、新弹珠和新被动。解锁进度存在各自的浏览器里。
- 结算时可以填名字上排行榜，标题页能看到大家的成绩。

## 现有内容

- **两层关卡**：
  - 「白骨坟场」：骷髅军团、白骨弩车两个精英，关底是骷髅王；
  - 「雪漫湾岸」：冰缚勇士、冰缚嚎叫者两个精英，关底是冰缚女王。
- **弹珠**：16 个基础弹珠和 45 种进化，任意两颗满级弹珠都能融合。
- **被动**：38 个基础被动和 8 种被动进化，包括会召唤石像士兵、金牛等友军的被动。
- **角色**：7 个，各有特性。
- **局域网排行榜**。

还没做的：其余 6 层关卡、小镇建造和局外成长、更多角色。

## 局域网联机（demo）

两种模式都要通过自带的服务端（`npm run serve`）打开游戏，因为它们走 `/ws` 上的 WebSocket。

- **局域网对战**：2–8 人的大逃杀，参考俄罗斯方块 99。选这个模式的人进同一个房间，第一个进来的是房主，可以加电脑（简单 / 普通 / 困难，在服务端运行）再开始。各自在自己的电脑上玩，用同一个种子，敌阵完全一样。左边是自己，右边是对手们的画面，来自对方浏览器发来的快照（一个对手时每秒 30 次，多个时 15 次），在本地平滑播放。连杀每 6 个送一行敌人，打败精英一次送 4 行，每次只打一个对手：用锁定策略选人（随机、反击正在打你的人、追击快倒下的人、夺取徽章最多的人，键盘 H J K L），或者直接点对手的画面。送来的行先在计量条里等几秒，自己的攻击会先抵消它们，落下时把整个敌阵往下推。最后一个攻击某人的玩家拿到击倒和他的徽章；徽章让攻击变大，同时被几个人盯上时攻击也会变大。对战不会暂停（升级选项显示在自己场地顶上，边打边选），关卡没有尽头，2 分钟后每 30 秒加速一级。活到最后的人获胜，出局的人可以观战还在场的任何人。
- **局域网合作**：选这个模式的人进同一个房间，第一个进来的人点开始。战斗在服务端运行，玩家只发送操作，接收每秒 30 次的画面快照并在本地插值平滑播放。队伍共用血量、弹珠、经验和升级。每多一个人多一份迷你弹珠，敌人血量 +50%，升级由队员轮流挑选，融合炉自动处理，掉线的人由自动驾驶接管。
- 还没做：合作中途加入、合作时各自选角色、合作模式下对自己移动的预测（现在自己的操作要经过一个来回再加上平滑缓冲才显示出来，局域网里约 0.1 秒）。
- `node tools/shot-versus.ts <目录> [网址]`、`node tools/shot-royale.ts <目录> [网址] [电脑数]` 和 `node tools/shot-coop.ts <目录> [网址]` 会开多个无头 Chrome 窗口打一局并截图；`node tools/versus-sim.ts` 和 `node tools/royale-sim.ts` 用自动驾驶无头对打，用来调数值。

## 运行与部署

需要 Node.js 22.18 或更高版本。

```bash
npm install
npm run build    # 类型检查并构建到 dist/
npm run serve    # 在 0.0.0.0:8080 提供游戏和排行榜（PORT=xxxx 可以换端口）
```

后台常驻运行：

```bash
setsid nohup node server.mjs > server.log 2>&1 < /dev/null &
kill $(pgrep -f '^node server.mjs$')   # 停止
```

排行榜存在 `data/scores.json` 里，删掉这个文件就是清空榜单；`DATA_DIR` 环境变量可以改存放位置。

## 开发

```bash
npm run dev               # Vite 开发服务器（这个模式下没有排行榜）
npm run check             # Prettier 格式检查 + TypeScript 类型检查
npm run format            # 自动整理格式
npm test                  # 单元测试：伤害公式、异常状态、合成配方、数据完整性
npm run sim -- 20         # 用自动驾驶无界面跑 20 局，看胜率、用时和受伤来源
npm run stress            # 把每种弹珠、被动和角色都放上场跑一遍（加 full 跑全部等级和融合）
node tools/shot.ts <目录>  # 用本机 Chrome 无头跑一局并截图（需要 /usr/bin/google-chrome）
```

- `npm run sim` 和 `npm run stress` 每一帧都会检查那些不报错的问题：数值变成 NaN、弹珠从背包里丢了、异常状态超过上限、整局打不出伤害等（见 `tools/invariants.ts`）。检查不通过就以非零状态退出，并打印可以重跑的种子或用例。同一个种子每次跑出来都一样，可以原样复现。
- 标成 `todo` 的测试记录的是已知 bug：照常运行，但在修好之前不会让测试失败。

- 技术栈：TypeScript + Vite + Canvas 2D + Web Audio，运行时没有任何依赖。服务端只用了 Node 自带的 `http` 模块。
- `src/game/` 是纯游戏逻辑，不依赖浏览器，所以可以在 Node 里无界面运行（`tools/sim.ts`）。
- 数值在 `src/game/config.ts` 和 `src/game/data/*.ts` 里，哪些照搬原作、哪些是估算见 `docs/NOTES.md`，资料来源见 `ATTRIBUTION.md`。
