# 数值说明：哪些照搬，哪些是估算

> 本文档以 [CC BY-SA 4.0](../LICENSES/CC-BY-SA-4.0.txt) 发布，说明游戏数据中哪些照搬自资料、哪些是估算。数据来源见 [ATTRIBUTION.md](../ATTRIBUTION.md)。

数值和机制主要来自 [BALL x PIT Wiki](https://ballxpit.wiki.gg/) 和 dood.gg，机制细节参考了评测、攻略和 Steam 官方截图（完整来源见 [ATTRIBUTION.md](../ATTRIBUTION.md)）。原作没有公开的数值都是估算的，按下面的原则选取，代码里也标了 `est.`。

## 照原作做的

- 场地：16:9 屏幕中间一条竖直走廊，地面持续向下卷动。走廊起始约 8 格宽，经过两个检查点后拓宽到 11 格、14 格（从截图估算宽度）。
- 操作：WASD 移动、鼠标瞄准（最低 20°）、按住发射、F 切换自动射击、右键召回、三档游戏速度。
- 弹珠生命周期：碰到墙、顶端和敌人都会反弹；从底边飞出后飞回玩家身边；用身体接住会立即重新入队。所有弹珠共用一条发射队列，每个特殊弹珠同一时间只有一颗在场上。
- 栏位与成长：4 个弹珠栏、4 个被动栏，最高 3 级；升级三选一；融合炉的裂变 / 融合 / 进化规则，包括「有进化配方的组合不能融合」。
- 数值：弹珠伤害 = 力量 × wiki 区间（新档战士打 25–46，和玩家实测的 25–44 吻合）；迷你弹珠 11–17 × 3 颗；各弹珠和被动的 L1/L2/L3 效果；敌人血量倍率（1x–6x，精英 20x）。
- 关卡结构：三段等长，前两段末尾各一个精英首领（精英没有血条，只显示裂纹，并且必掉融合炉），最后是骷髅王；右侧进度条上有两个「!」检查点。
- 骷髅王：左右摇摆、扇形骨头弹幕、连发、扫射、甩手（有预警，飞出去再飞回来）、召唤小兵，半血时断一只手臂。

## 估算或自己设计的

| 项目 | 取值 | 依据 |
|---|---|---|
| 玩家血量 | 耐力 × 15 + 10（战士 100） | 按治疗量和受伤量反推，大约 100 |
| 移速 / 球速 / 射速 | 4.2 格/秒、12.5 格/秒、4.2 发/秒 | 手感 |
| 卷动速度 | 0.34 格/秒（下方没有敌人时 1.4） | 一局大约 9–10 分钟 |
| 每段行数 | 56 行 | 同上 |
| 敌人基础血量 | 80，每行 +0.9% | 开局 3–4 发打死一只，后期靠进化 |
| 敌人伤害 | 小怪 5–14，骷髅王骨头 8 | 资料只提到 Boss 一发约 20 |
| 弹珠等级加成 | L2 ×1.25，L3 ×1.5 | wiki 两处说法矛盾（每级 +33%，或不变），取了折中 |
| 暴击 | 3% + 敏捷 × 0.5%，伤害 ×2 | 暴击倍率没有公开 |
| 经验曲线 | 6 + 2.6 ×（等级 − 1） | 一局能升 20–28 级 |
| 融合炉掉率 | 精英必掉，普通敌人 0.4% | 资料只说是「稀有」 |
| 裂变升级次数 | 1–5 次 | fandom 的说法 |
| 药水 | 2.5% 掉率，回复 20 | 资料只说有红色药水 |
| 被动 L2/L3 | 大多按每级 +50% 推算 | 约 45 个被动没有公开 L2/L3 的数值。丰饶之角 3 级多生 1–2 颗、遥控引爆器和织风者生成与被动同级的弹珠，参考了玩家对满级效果的描述 |
| 自毁类进化弹珠的冷却 | 烟花、蚊群 3 秒，天劫 4 秒 | wiki 没写，沿用巢囊的 3 秒 |

## 资料缺失、按名字设计的部分

- **骷髅蛮兵、骷髅猛兽、白骨巨兽、骷髅堡垒**：wiki 没有行为描述。目前蛮兵、巨兽、堡垒是血多伤害高的近战；猛兽会时不时往前扑一格。
- **骷髅主教**：资料说弓手是这一关唯一的远程小怪，所以主教做成了辅助，会定期给周围的骷髅回血。
- **骷髅军团**（第一个精英）：3×2 的盾阵，交替放三连箭和召唤小兵。
- **白骨弩车**（第二个精英）：资料写的是「朝玩家射出一波波箭」，做成了扇形箭雨，外加一发有红线预警的重弩。
- **骷髅王的弱点**：dood.gg 说只有王冠吃伤害，Deltias 的攻略说下巴也算。为了让新手打得动，王冠和下巴都设成了弱点。
- **敌人冲到底部**：打你一下然后消失。原作里它们会不会一直留在底部，资料没说清楚。

## 第二层「雪漫湾岸」

- 有原作资料的部分：敌人名单和血量倍率；「盾卫：盾牌那一面免疫弹珠伤害」「投手：冰锥命中会冻住玩家」「勇士：正面免疫」「嚎叫者：投出多根冰锥」；女王被冰盾环绕、会用盾牌冲刺（盾牌飞出后沿原路返回）、能召唤投手；通关奖励。
- 估算的部分：关卡血量 ×1.35、伤害 ×1.15。原作玩家打到第二层时已经有小镇建筑加成，这里没有局外成长，所以倍率压得比较低。另外，玩家被冻住时只是不能移动，仍然可以射击；冰缚战团、蛮兵、猛兽、堡垒的行为按名字设计。冰系敌人的中文名没有找到官方译名，是本项目自己翻译的。
- 女王的「盾墙」是从攻略里「a wide shield / big shield」的描述推测出来的：四面盾在她身下排成一排，持续 5 秒，逼你打墙反弹。
- 冰缚盾卫的刷法是自己定的：每层开头 10 行不刷盾卫（和高血量敌人一样），之后每一行最多只有四分之一是盾卫。原先同一种敌人可以刷成整块方阵，开局偶尔会出现一整块盾卫，弹珠全被弹回来，几十秒就输了。

## 角色特性的实现

- 沉思者：升级时自动替你选，优先升级已有的弹珠。
- 顽固老兵：弹珠碰到任意墙壁之前都会穿透敌人。
- 空巢老人：没有迷你弹珠；每次射击额外射出 1 颗伤害减半、2.5 秒后消失的复制弹珠。不加这个限制的话，复制弹珠会在顶端越积越多，强度失控。
- 夫妇：镜像复制弹珠，伤害减半，同样 2.5 秒后消失。

## 各角色强弱（自动驾驶，第一层）

战士约 45%，忏悔者和沉思者差不多，夫妇和空巢老人明显更强（接近全胜），快枪手很弱（约 5%）。快枪手的力量只有 2，单发伤害是战士的四分之一；射速翻倍只在有球排队时才有用。属性照原作填写，没有为了平衡去改。

## 平衡测试

`node tools/sim.ts 20` 用自动驾驶跑 20 局。`node tools/stress.ts full` 会把每种弹珠（每个等级、单独和融合）、每个被动和每个角色都放上场跑一遍，并列出伤害明显偏离同类中位数的弹珠，方便发现数值或机制问题。目前战士在第一层的胜率大约 40%–50%，一局 8–10 分钟；在第二层大约 35%，一局 11 分钟左右（参数：`node tools/sim.ts 12 warrior boneyard full snowy`）。自动驾驶不太会接球，也不会刻意打出王冠弹射，真人应该比它打得好。觉得难或简单，可以调 `src/game/config.ts` 里的 `enemyBaseHp`、`enemyHpGrowthPerRow` 和 `scrollSpeed`。
